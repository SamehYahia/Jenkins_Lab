# DevOps Project: Node.js with Jenkins CI/CD

هذا المشروع عبارة عن تطبيق Node.js تم إعداده للعمل في بيئة DevOps متكاملة، حيث يتم استخدام **Docker** لإنشاء بيئة تشغيل موحدة و **Jenkins** لأتمتة عمليات الـ CI/CD.

## 🚀 نبذة عن المشروع
تم بناء هذا المشروع كجزء من رحلة تعلم الـ DevOps، ويهدف إلى ربط التطوير بالتشغيل من خلال:
- **Dockerization**: تحويل تطبيق Node.js إلى حاوية قابلة للتشغيل في أي بيئة.
- **CI/CD Pipeline**: أتمتة عمليات البناء والتشغيل باستخدام Jenkinsfile.

## 🛠 الأدوات المستخدمة
- **Node.js**: بيئة تشغيل التطبيق.
- **Docker**: لبناء وإدارة الحاويات.
- **Jenkins**: لأتمتة خط الإنتاج (Pipeline).
- **GitHub**: لاستضافة الكود المصدري.
